# 使用说明

## 从电影导览开始

打开HTML，点击“开始电影导览”，不用操作就会按战役进程观看。开始按钮同时请求启用音频；音量、背景音乐和静音均可调整。点击“自由进入战场”则从暂停与自由观察开始。

## 看时间

空格播放/暂停；底栏选择¼、½、1、2、4倍速。拖动时间轴可以立即定位，左右方向键前后五秒，Shift加方向键前后十五秒。

右上角“关键节点”打开八章目录。点击章节时，画面会快速推进或回看，并平滑转移镜头。底栏“⏭”或英文右方括号 `] `前往下一重点。“取消”按钮或Esc可中断这次快进。

底栏“↻”循环当前章节，再次点击关闭；“↺”则从头重播。章节循环是演示回放，不是改变战役结果。

## 看角度

鼠标左键拖动旋转，滚轮缩放，右键或Shift拖动平移。手机单指旋转、双指捏合缩放和双指平移。点击部队标牌可以跟拍，也可用上方的部队选择器。

六个机位为后随、侧拍、迎面、环绕、俯瞰、交锋线。暂停时部队停止，环绕也不会按墙钟继续旋转，但仍可手动观察。

侧栏的小图是实时计算的局部战术示意，不是第二路三维摄像机。点击小图或下方的“靠近这支部队／放大交锋处”，主三维镜头会真正移近。按D或点击“返回电影导览”，回到此刻的自动机位，不重播。

## 保持可读与顺畅

设置中可分别关闭部队标牌、行进方向与速度线、浮动地名、章节动态标题和局部示意。窄屏通过右上角“战况”打开侧栏。净览隐藏控件，按H或点击右下方恢复按钮返回。

画质包括自动、流畅优先、均衡、清晰优先。画质不会删除叙事部队或改变时间线；远处使用简化表示。切换画质不等于改变历史兵力。

设置中“保存PNG”导出三维战场截图与片段说明；它不包含所有交互控件。诊断JSON记录最近最多900个界面帧及其中实际重绘的帧，文件只保存在本地，不上传。

## 故障说明

主程序使用WebGL2。初始化失败会显示错误面板，不会悄悄换成静态图片。图形上下文中断会尝试恢复；恢复时需要重新启动页面。切到后台会暂停，避免回来时错过战役。

时间轴可即时跳转；“关键节点”和“⏭”则使用连续快进。两种操作有意不同。
