# GAME-juluzhizhan

## 巨鹿之战 · 可交互三维战役演示

这是一个把巨鹿之战做成“可以观看、可以暂停、可以回看、可以自由换角度观察”的三维交互程序。

作者：**晓斌教您学急救**

> 目标不是把历史做成可以改变结局的游戏，而是做成一个能够随时间推进、又可以随时停下来观察的三维历史现场。

## 直接体验

下载仓库后，直接双击根目录的 `index.html` 即可运行。

建议使用新版 Chrome / Edge，并开启硬件加速。程序使用 WebGL2，不依赖在线素材。

## 目前包含什么

- 巨鹿被围、先遣渡河、主力渡河与破釜沉舟、断粮道、楚秦交锋、诸侯进击、巨鹿解围等八个章节
- 约五分钟自动推进的战役时间线
- 三十个电影式导览镜头
- 暂停、拖动时间轴、章节跳转、1/4×、1/2×、1×、2×、4×速度
- 全景、渡口、粮道、交锋、城楼等观察位置
- 后随、侧拍、迎面、环绕、俯瞰、交锋线等部队跟随机位
- 部队名称、状态、补给、方向线、速度短线、小地图和比例尺
- 局部放大、章节循环、截图、净览、全屏、声音和画质设置
- 电脑与手机触控适配

## 史料与画面边界

程序主要依据《史记》相关篇目组织事件主线。

但具体河道形状、城池外观、军阵间距、分队路线、交锋动作，以及演示里的距离和速度，属于为了理解关系而做的示意重建，不应当作已经考证确认的历史实测。
