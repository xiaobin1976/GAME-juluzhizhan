# GAME-juluzhizhan

## 巨鹿之战 · 可交互三维战役演示

这是一个把巨鹿之战做成**可以观看、可以暂停、可以回看、可以自由换角度观察**的三维交互程序。

作者：**晓斌教您学急救**

> 这里不是让玩家改变历史，而是把一场战役做成可以反复观察的三维历史现场。

## 直接体验

仓库根目录的 **`index.html`** 是完整单文件版本，下载后直接用新版 Chrome / Edge 打开即可运行。

程序使用 WebGL2，正常运行不依赖在线素材。

## 源代码

原始模块化源码已放在 **`src/`** 中，包括页面、样式、WebGL 渲染、战役时间线、场景、镜头导演、连续运动、电影交互、声音和应用入口。

重新构建单文件版本：

```bash
python build.py
```

构建后会生成：

```
巨鹿之战_V3_连续运镜优化版.html
```

## 目前包含

- 巨鹿被围、先遣渡河、主力渡河与破釜沉舟、断粮道、楚秦交锋、诸侯进击、巨鹿解围等八个章节
- 约五分钟自动推进的战役时间线
- 三十个电影式导览镜头
- 暂停、拖动时间轴、章节跳转、¼×、½×、1×、2×、4×速度
- 全景、渡口、粮道、交锋、城楼等观察位置
- 后随、侧拍、迎面、环绕、俯瞰、交锋线等部队跟随机位
- 部队名称、状态、补给、方向线、速度短线、小地图和比例尺
- 局部放大、章节循环、截图、净览、全屏、声音和画质设置
- 电脑与手机触控适配

## 史料与画面边界

程序主要依据《史记》相关篇目组织事件主线。

具体河道形状、城池外观、军阵间距、分队路线、交锋动作，以及演示中的距离和速度，属于为了理解空间关系而做的示意重建，不应当作已经考证确认的历史实测。

详细说明见 `docs/史料与重建边界.md`。

## 运行建议

- 桌面端优先使用 Chrome / Edge 新版浏览器
- 建议开启硬件加速
- 手机建议横屏
- 较弱设备可选择“流畅优先”
- 真实帧率受显卡、浏览器、屏幕分辨率和画质设置影响
