# 史料与重建边界

## 核心文本

- 《史记·项羽本纪》：https://zh.wikisource.org/wiki/史記/卷007
- 《史记·张耳陈馀列传》：https://zh.wikisource.org/wiki/史記/卷089
- 《史记·黥布列传》：https://zh.wikisource.org/wiki/史記/卷091

采用公开文本便于复核；不同篇章的叙事重点并不完全相同。导览主线并不代表对每一次局部交锋的精确复原。

## 人物与编组

项羽、当阳君英布、蒲将军、王离、章邯、陈馀、张敖、张耳、赵王歇，有相关身份或行动记载。画面中的“西侧分队”“粮道分队”“护道分队”“城西部”“北东部”均为解说性视觉编组，没有给它们安上史书没有明确记载的指挥官。

《项羽本纪》记当阳君、蒲将军率两万人先渡河；《黥布列传》补充当阳君身份。两万人不能进一步无依据地拆成两个将领各自的人数。

## 空间与时间

巨鹿城、南部秦军、北部援军、输粮甬道的相对关系用于组织三维演示。城墙形状、各营垒坐标、道路宽度、地形高度、渡口位置与各队具体路径均为示意。河道标注和视觉位置不是关于古今水文位置的测绘结论。

五分钟是压缩的叙事时间，不是战役持续时间。模型中每一米、每一秒、每一个士兵实例都不能直接换算成准确历史数字。比例尺只服务于场景内观察，行进速度显示的是模型路线的导数。

## 战斗与结局

断粮、反复交战、援军进击、围城军败与解围构成导演叙事。没有把“九战”虚构成九套可考的详细部署。个体挥兵器、队形松动、伤亡和退却都是示意动作。

章邯部退却之后的相持与投降属于后续；不在解围瞬间表现为全体秦军一并投降。旁白与说明对诸侯进击等内容参考《张耳陈馀列传》，而不是把全部胜负变化归于单一口号。
